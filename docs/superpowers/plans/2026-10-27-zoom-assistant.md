# Zoom Assistant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu-bar app that listens to system audio, transcribes Ukrainian speech locally with Whisper, detects questions, and streams Claude Haiku 5.5 answers (with screen and optional knowledge-base context) into a floating Liquid Glass card that is excluded from screen sharing where macOS allows it.

**Architecture:** All testable logic (audio segmentation, Claude request building, SSE parsing, the answer pipeline, knowledge base) lives in a local Swift package `AssistantCore`, tested with `swift test`. The app target `ZoomAssistant` (generated by XcodeGen) holds only OS-bound code: ScreenCaptureKit capture, WhisperKit, AppKit panel, SwiftUI views, settings. The app talks to the core through small protocols (`SpeechTranscribing`, `ScreenshotProviding`, `MessageStreaming`, `KnowledgeProviding`).

**Tech Stack:** Swift 6, SwiftUI + AppKit, ScreenCaptureKit, PDFKit, WhisperKit (package `argmax-oss-swift`), Claude Messages API over raw HTTP (no official Swift SDK), Swift Testing, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-27-zoom-assistant-design.md`

## Global Constraints

- Every `xcodebuild`, `swift build`, `swift test` command runs with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` (xcode-select points to Command Line Tools on this Mac).
- Deployment target macOS 26.0; Swift 6 language mode; Xcode 27.1.
- Bundle id `local.zoomassistant.app`; display name `Асистент`; `LSUIElement = YES`; App Sandbox off; no private APIs (no `CGS*`, no Zoom process manipulation).
- Every window the app creates gets `sharingType = .none`.
- Claude: endpoint `https://api.anthropic.com/v1/messages`, header `anthropic-version: 2026-10-21`, model `claude-haiku-5-5`, `thinking: {"type":"disabled"}`, `output_config: {"effort":"low"}`, `max_tokens: 2048`, `stream: true`. Never send `temperature`, `top_p`, `top_k` (400 on this API version).
- Whisper: model `large-v3-v20240930_626MB` (large-v3-turbo, quantized), language `uk`, input 16 kHz mono `Float`.
- Pinned values: silence to end an utterance 0.7 s; min speech 0.3 s; max utterance 15 s; frame 20 ms; speech RMS threshold 0.01; min words to send 3; transcript window 180 s; last 3 Q&A pairs; screenshot long side 1500 px, JPEG quality 0.7; inline KB threshold 80 000 tokens; KB cache TTL `1h`; max tool rounds 3; global hotkey ⌥⌘H.
- No answer sentinel: `∅`.
- API key stored only in Keychain (service `local.zoomassistant.app`, account `anthropic-api-key`). Nothing else persists between launches except card position and settings (UserDefaults).
- UI copy is Ukrainian, exact strings:
  - `Слухаю` (audio present), `Очікую звук` (silence)
  - `шукаю в базі…`
  - history line: `↑ ще 1 попередня відповідь` / `↑ ще 2 попередні відповіді` (2–4) / `↑ ще 5 попередніх відповідей` (0, 5–20, 11–14 …)
  - `Додайте ключ у налаштуваннях`
  - `Немає дозволу на запис екрана` + button `Відкрити налаштування`
  - `Завантаження моделі розпізнавання… 42%`
  - `Помилка API (%d). Спробую на наступному питанні.` / `Немає мережі. Спробую на наступному питанні.`
  - `Модель відмовилась відповідати.`
  - input placeholder `Спитати самому…`
  - menu: `Показати / сховати картку`, `Налаштування…`, `Вийти`
  - latency format: `0,8 с · 140 ток/с` (comma decimal, one digit)

## Review Focus

1. **Whisper hallucinations on non-speech** (music, Zoom join chimes, keyboard): Whisper emits phrases like «Дякую за перегляд!» or «Субтитри зроблені…». Expected: never sent to Claude. Test in Task 5 (`hallucinationsAreDropped`).
2. **Speaker talks for a long time without pausing**: expected: utterance is cut at 15 s and processed, not held forever. Test in Task 2 (`longSpeechIsCutAtMax`).
3. **Sentinel with whitespace or punctuation** (`"\n∅."`, `" ∅"`) and real answers that contain `∅` later: expected: the first is suppressed, the second shown in full. Test in Task 3.
4. **API fails mid-answer** (529 overloaded, network drop after some text): expected: text already shown stays, an error line appears, next utterance works. Test in Task 6 (`midStreamFailureKeepsPartialAnswer`).
5. **Broken knowledge-base file** (encrypted/corrupt PDF, unsupported extension, empty folder): expected: file skipped with a warning, the rest of the KB and the app keep working. Test in Task 9 (`unreadableFilesAreSkipped`).
